# ParkGuard AI – интеллектуальная система детекции нарушений парковки

Автоматическое выявление автомобилей на тротуарах с помощью компьютерного зрения.

## 🚀 Возможности
- Сегментация дороги, тротуара, пешеходного перехода и автомобилей
- Автоматическое определение нарушителей (машина на тротуаре)
- Пространственный фильтр для исключения ложных срабатываний
- Удобный веб-интерфейс с настройкой порогов
- Режим "Тщательная проверка" (Deep Check)

## 🛠️ Установка и запуск

1. Клонируйте репозиторий:
    git clone https://github.com/your-username/parkguard-ai.git
    cd parkguard-ai
2. Создайте виртуальное окружение и установите зависимости:
    python -m venv .venv
    .venv\Scripts\activate # для Windows
    pip install -r requirements.txt
3. Скачайте обученную модель `best.pt` по ссылке из файла `models/model_link.txt`
и поместите её в папку `models/`.

4. Запустите веб-сервер:
    python app_server.py
5. 
Откройте браузер и перейдите по адресу http://127.0.0.1:5000

## 📂 Структура проекта
- `app_server.py` – веб-интерфейс на Flask
- `models/` – папка с обученной моделью (скачивается отдельно)
- `dataset_51_demo/` – примеры размеченных изображений
- `runs/` – графики обучения
- `presentation/` – презентация и текст защиты

## ⚙️ Технологии
Python, PyTorch, Ultralytics, YOLO11m-seg, Flask, OpenCV
